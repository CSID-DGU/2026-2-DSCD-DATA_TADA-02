# 제 발표 피드백 반영사항

## 경쟁 심화란?

- 상권 포화(과거데이터를 분석하여 더 이상 매출이 오르지않고 나눠먹기상태-임계점?가되는지점을 경쟁심화된 상태로본다)
    - 예) 전체 매출액 / 상권 점포수 → 밀도

## 경쟁 심화 지수

1. 논문 리서치
2. 논문 수식 우리 데이터에 적용
3. 수치의 유효성 검증

또는 요인분석 등을 통해 새로운 지수 정의

## 모델 검증 방법

- 과거의 데이터로 과거의 데이터를 예측 X
- 정확한 시계열 모델 예측 방법을 제시
    - 예) 21년도 1~3분기를 가지고 21년도 4분기를 예측

## 모델 예측 대상

- 경쟁심화 지수 X ( 데이터 누수 심각)
- 따라서 점포수, 매출액 같은 데이터를 예측하는 방향으로
