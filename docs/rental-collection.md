# 서울 상가 임대 매물 수집

`Run-RentalCollection.ps1`을 실행하면 상가114 공개 지도에서 서울 점포 월세 광고를 조회하고, 주소와 월세를 정리해 상권 경계에 연결한다. 반복 실행에는 Codex나 LLM API가 필요하지 않다.

## 실행

저장소 루트에서 실행한다. Windows의 일반 Python 3.13과 `pyshp`, `pyproj`, `shapely`가 필요하다. 프로젝트에서 보유한 1,650개 상권 경계 ZIP을 기본값으로 사용한다. 다른 경계 파일은 `-BoundaryPath`로 지정한다.

```powershell
powershell.exe -NoProfile -File .\scripts\Run-RentalCollection.ps1
```

Windows 작업 스케줄러에서는 같은 명령을 등록하고, `-File` 뒤에 스크립트의 절대 경로를 넣는다. 예약 시각을 놓치면 사용 가능할 때 실행하고, 이전 실행이 진행 중이면 새 실행을 시작하지 않도록 작업 설정에서 선택할 수 있다.

## 결과 확인

`data/rental_collection/` 아래에 한국 시각 기준 실행 폴더가 생성된다. `-OutputDirectory`로 다른 경로를 지정할 수 있다.

| 파일 | 들어 있는 내용 |
| --- | --- |
| `summary.json` | 조회 페이지 수, 출처 응답 행 수, 사용 가능한 매물 및 제외 건수, 상권별 확보 범위 요약, 이전 회차 대비 변동 수 |
| `rentals.csv` | 매물번호, 출처 URL, 주소, 원 단위 월세와 보증금, 층, 면적 원문, 등록일, 확인 시각, 공개 좌표 |
| `area_memberships.csv` | 좌표가 포함되는 상권 코드와 매물번호. 한 매물이 여러 상권에 포함될 수 있다. |
| `area_coverage.csv` | 전체 상권의 매물 수, 공개 주소 수, 주소 5곳까지 부족한 수, 최근 90일에 등록된 매물 및 주소 수 |
| `changes.csv` | 앞선 결과와 대조해 추가로 관측한 매물, 값이 바뀐 매물, 이번 결과에서 관측되지 않은 매물 |

매 회차에 공개 목록을 새로 조회하므로 기존 매물의 월세 변경도 반영된다. 앞선 실행 폴더가 없으면 보유한 10월 25일 상가114 점포 자료와 월세 및 보증금을 대조한다. 그 자료도 없으면 첫 회차를 이후 비교 기준으로 사용한다. 목록 페이지를 모두 확인하고 파일을 저장한 뒤에 실행 폴더를 남긴다. 실행이 중단되면 기존 결과를 바탕으로 다음 회차를 계속 운영할 수 있다. PowerShell의 종료 코드가 0이면 실행이 완료됐다.

공개 목록이 월세로 분류한 광고의 제시 조건을 수집한다. 계약 체결 여부와 계약 금액은 현장에서 확인해야 한다. `not_observed`는 최신 수집 결과에서 해당 매물번호를 찾지 못했다는 뜻이다. 최근 90일은 한국 시간 기준 수집 당일을 포함하며 광고 등록일로 계산한다. 등록일이 없으면 전체 수에 포함하고 최근 수에서 제외한다. 상권별 주소 수는 도로명 또는 지번 표기를 기준으로 센다. 원자료와 결과는 로컬에 저장한다.
