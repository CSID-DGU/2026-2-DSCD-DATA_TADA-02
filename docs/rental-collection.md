# 서울 상가 임대 매물 수집

`Run-RentalCollection.ps1`을 실행하면 공개 상가 매물의 원본 링크, 주소와 임대 조건을 모아 서울 상권 경계에 연결한다. 등록일에 관계없이 공개 목록에 있는 매물을 대상으로 한다. 반복 실행에는 Codex나 LLM API가 필요하지 않다.

## 실행

저장소 루트에서 실행한다. Windows의 일반 Python 3.13과 `pyshp`, `pyproj`, `shapely`, Node.js가 필요하다. 프로젝트에서 보유한 1,650개 상권 경계 ZIP을 기본값으로 사용한다. 다른 경계 파일은 `-BoundaryPath`로 지정한다.

```powershell
powershell.exe -NoProfile -File .\scripts\Run-RentalCollection.ps1
```

Windows 작업 스케줄러에서는 같은 명령을 등록하고, `-File` 뒤에 스크립트의 절대 경로를 넣는다. 예약 시각을 놓치면 사용 가능할 때 실행하고, 이전 실행이 진행 중이면 새 실행을 시작하지 않도록 작업 설정에서 선택할 수 있다.

## 수집 범위

| 출처 | 공개 목록과 수집 기준 |
| --- | --- |
| 상가114 일반상가 | 월세 필터의 모든 목록 페이지를 조회한다. 서울 광고는 주소나 가격의 누락을 표시해 보관하고, 빈 항목을 공개 상세 화면에서 다시 확인한다. |
| 상가114 권리금 상가 | 공개 목록의 서울 사업 양도 후보를 모은다. 설명에 명시된 월세와 보증금만 가격으로 기록한다. 주소 공개 설정에 따라 좌표 사용 여부를 결정한다. |
| 딱자리 | 공개 사이트맵의 매물별 링크를 확인한다. 표기된 보증금과 월세, 공개 주소와 일치하는 지도 좌표를 보존한다. |
| 헤이빌딩 | 공개 상가 목록에서 연결된 상세 페이지를 조회한다. 서울 상가의 월세 또는 월세가 붙은 반전세를 보존한다. 동 단위 주소는 지도 배정에 사용하지 않는다. |

딱자리와 헤이빌딩의 상세 조회 기록은 출력 폴더 아래 `ddak-YYYYMMDD`, `heybd-YYYYMMDD`에 저장한다. 같은 날 재실행하면 목록을 다시 조회하고 기존 상세 조회 결과를 재사용한다. 별도 회차의 작업 폴더를 사용하려면 `-DdakCheckpointPath`, `-HeybdCheckpointPath`로 새 경로를 지정한다. `-SanggaOnly`는 상가114의 두 목록을 실행한다. 이미 만든 상가114 실행 폴더가 있으면 `-SanggaSnapshotPath`로 지정해 다른 출처와 합칠 수 있다.

## 결과 확인

`data/rental_collection/` 아래에 한국 시각 기준 실행 폴더가 생성된다. `-OutputDirectory`로 다른 경로를 지정할 수 있다.

| 파일 | 들어 있는 내용 |
| --- | --- |
| `summary.json` | 출처별 조회 범위와 저장 수, 주소 및 가격이 갖춰진 수, 상권별 확보 범위, 이전 회차 대비 변동 수 |
| `rentals.csv` | 매물번호, `source_url`, 게시 종류, 주소, 원 단위 월세와 보증금, 좌표, 확인 시각, 누락 항목 |
| `complete_rentals.csv` | `rentals.csv`에서 상세 주소와 양의 월세, 숫자 보증금이 확인된 행. 명시된 보증금 0원도 포함한다. |
| `area_memberships.csv` | 좌표가 포함되는 상권 코드와 매물번호. 한 매물이 여러 상권에 포함될 수 있다. |
| `area_coverage.csv` | 전체 상권의 매물 수, 공개 주소 수, 주소 5곳까지 부족한 수, 기본 정보가 모두 있는 매물과 주소 수 |
| `changes.csv` | 앞선 결과와 대조해 추가로 관측한 매물, 값이 바뀐 매물, 이번 결과에서 관측되지 않은 매물 |

같은 출처 구성을 사용한 마지막 실행과 비교한다. 해당 구성이 처음이면 첫 회차가 이후 비교 기준이 된다. 출처 목록과 결과 파일을 확인한 뒤에 실행 폴더를 남긴다. PowerShell 종료 코드 0은 수집과 저장이 완료됐다는 뜻이다.

공개 광고의 제시 조건을 수집한다. 계약 체결 여부와 계약 금액은 원본 매물에서 확인해야 한다. `not_observed`는 최신 수집 결과에서 해당 매물번호를 찾지 못했다는 뜻이다. 같은 점포가 여러 출처에 게시되면 원본 링크별로 보존한다. 상권별 주소 수는 도로명 또는 지번 표기를 기준으로 센다. 원자료와 결과는 로컬에 저장한다.
