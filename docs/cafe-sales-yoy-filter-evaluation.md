# 카페 매출의 전년 동분기 급등 감쇠 검증

11월 18일 모델과 같은 2025년 1분기~2026년 2분기 카페 매출 예측 11,513건으로 비교했다. 1분기 뒤 6,284건과 2분기 뒤 5,229건을 사용했다. 이전에 여러 모형을 비교한 기간이다. 추가로 수집한 독립 시험 자료는 없다.

## 적용한 방법

- 같은 상권의 전년 동분기 대비 매출 증가율이 과거 증가율의 중앙값에서 크게 벗어난 경우를 찾았다. 최근 매출 수준을 계절에 맞게 조정한 비교에서도 높고, 과거 여러 분기가 함께 높아진 경우가 아닐 때만 감쇠했다. 이전 연도의 매출이 유독 낮아 증가율이 커 보이는 경우를 줄이려는 조건이다.
- 입력 감쇠는 급등 중 평소 변동 범위를 넘는 부분만 줄여 학습과 예측에 반영했다. 예측 감쇠는 학습을 고정했다. 같은 모델을 그대로 적용한 결과와 감쇠한 입력을 적용한 결과를 비교하고, 급등 때문에 높아진 예측에만 차이의 일부를 줄였다.
- 2024년 자료에서 입력 감쇠 7가지와 예측 감쇠 5가지를 비교하고 각각 하나를 정했다. 모델 하나로 첫 분기 매출을 예측한 뒤 그 예측으로 다음 분기를 계산했다. 실제 첫 분기 매출이 둘째 분기 입력에 들어가지 않으며 거래와 점포 자료는 두 번 모두 기준 분기까지만 사용했다. 평가의 실제 매출은 급등을 포함했다.

## 검증 결과

| 방법 | 전체 MAPE | 전체 MSE, (억 원)² | 전체 방향 적중률 | 둘째 분기 MSE, (억 원)² |
| --- | ---: | ---: | ---: | ---: |
| 11월 18일 모델 | 24.497% | 3.886 | 70.51% | 4.801 |
| 전년 동분기 급등 입력 감쇠의 비교군 | 24.319% | 4.328 | 70.25% | 5.679 |
| 전년 동분기 급등 입력 감쇠 | 24.375% | 4.515 | 70.40% | 5.814 |
| 전년 동분기 급등 예측 감쇠의 비교군 | 24.493% | 4.119 | 70.54% | 5.352 |
| 전년 동분기 급등 예측 감쇠 | 24.508% | 4.183 | 70.50% | 5.456 |

비교군은 각 감쇠 설정의 모델 학습 조건을 유지한 채 급등 감쇠를 껐다. 예측 감쇠의 비교군과 감쇠 모형은 같은 적합 모델을 사용했다. 전년 동분기 성장률을 예측의 기준값 전반에 반영한 초기 실험도 2024년 선택 설정의 평가 방향 적중률이 66.69%에 그쳤다.

### 급등으로 표시된 표본

- 급등으로 표시된 1,058건에서 예측 감쇠의 MAPE는 **26.22%에서 26.45%**, MSE는 **1.925에서 2.616**으로 증가했다.
- 급등으로 표시된 첫 분기 예측 592건 중 **314건(53.0%)**에서 다음 분기의 전년 동분기 증가율이 낮아졌다. **305건(51.5%)**은 이전 증가율 중앙값에 가까워졌다. 급등으로 판단하는 시점에 다음 분기 값은 알 수 없으므로, 이 지표는 과거 결과의 해석에만 썼다.
- 예측 감쇠로 실제 예측액을 낮춘 962건 중 **605건(62.9%)**은 감쇠 전에도 실제보다 낮았다. 하락이나 완화가 일부 관측돼도 같은 모델의 예측에 추가로 하향 조정이 필요한 것과는 별개였다.
- 두 감쇠 방식 모두 감쇠를 끈 자기 비교군보다 금액 오차가 커서 실험 후보로 둔다.

## 재현

- [입력 감쇠](../scripts/evaluate_cafe_sales_yoy_filter.py)와 [예측 감쇠](../scripts/evaluate_cafe_sales_yoy_guard.py)를 정규 CPython 3.13으로 실행했다. 기존 카페 패널과 11월 18일 예측을 사용하며 두 스크립트에서 `--panel`, `--previous`, `--output`을 지정할 수 있다.
- 각 방법의 과거 예측 11,513건과 2026년 2분기 기준 미래 예측 3,016건을 저장했다. 저장한 모델을 다시 읽어 두 분기 예측을 재현했고, 예측 CSV에서 MAPE와 MSE, 방향 지표, 두 단계 예측 연결을 별도로 검산했다.
