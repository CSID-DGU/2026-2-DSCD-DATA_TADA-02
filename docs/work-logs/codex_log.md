# Codex 작업 로그

## 2026-11-20 후보 상권 선택과 비교 한도를 3개로 변경

- 사용자 요청에 따라 후보 선택 한도를 5개에서 3개로 변경. 선택 토글, 안내 문구, 선택 개수 표시, URL 후보 목록에 공통 프론트 상수를 사용하고 기존 5개 비교 주소는 앞의 3개만 복원.
- 서버의 비교/해설 요청 검증과 설정 응답에 최대 3개를 적용. 4개/5개 요청은 422로 거부하며 기존 임시 자료가 있는 5개 상권 목록과 독립 상세분석은 유지.
- README, 현재 API 명세/OpenAPI, 서버 설명과 지도/검증 안내, 생성 구조도를 갱신. 과거 설계/배포 검증의 5개 기록은 보존하고 현재 한도가 달라졌음을 명시.
- 주요 파일: `frontend/src/selection.mjs`, `App.tsx`, `backend/app/schemas.py`, `main.py`, 선택/API 테스트, 관련 문서와 `scripts/render_architecture.py`.
- 검증: TypeScript 검사와 Vite production build, 프론트 테스트 4개 및 백엔드 테스트 27개 통과. Chrome에서 네 번째 선택 거부, 선택 해제 후 대체, 3개 비교, 기존 5개 URL 제한, 모바일 카드 이동과 가로 넘침을 확인. 앱 콘솔 오류 없음.
- 로컬 데모 서버를 재시작하고 실제 `/config`의 `max_candidates=3`, 임시 상권 5개 유지, 4개 비교 요청의 HTTP 422를 확인. 운영 배포는 수행하지 않음.

## 2026-11-20 비교 화면 정리와 독립 상세분석 메뉴 추가

- 사용자 요청에 따라 매출 비교 카드의 분기별 추이 그래프와 관련 컴포넌트/CSS를 제거. 상세 매출의 과거 추세 및 예측 그래프는 유지.
- 종합해설의 상권별 막대그래프 카드 맨 아래에 최소 150px 높이의 AI 해설 공간을 추가. 기존 전체 후보 종합 해설과 별도 영역이며, 상권별 실제 LLM 호출은 연결하지 않음.
- 상단에 상세 상권 분석 메뉴를 항상 표시하고 후보 선택 없이 진입 가능하도록 변경. 전체 상권 검색/선택 UI를 추가하고 비교 후보와 상세 분석 대상 상권을 분리. 비교 후보에 없는 상권도 분석할 수 있고 비교로 돌아갈 때 기존 후보를 유지.
- 상세분석의 상권 코드만 포함한 URL과 새로고침을 지원. 모바일에서는 메뉴를 별도 행에 배치해 3개 메뉴를 모두 표시.
- 주요 파일: `frontend/src/App.tsx`, `DetailAreaPicker.tsx`, `OverviewComparison.tsx`, `report-layout.css`, `README.md`.
- 검증: TypeScript 검사, Vite production build, 프론트 테스트 4개 통과. Chrome에서 후보 없는 상세 진입/검색/전환, 직접 URL/새로고침, 후보 외 상권 분석 후 비교 후보 보존, 매출 추이 제거, 상권별 해설 영역의 위치/높이, 모바일 메뉴/가로 넘침을 확인. 앱 JavaScript 콘솔 오류 없음.
- 기존 로컬 데모 서버의 빌드 결과에 반영. 검증은 데모 모드이며 운영 배포와 상권별 해설 API 추가는 이번 변경 범위에 포함하지 않음.

## 2026-11-20 12주차 보고서 3번에 맞춰 화면 내용과 탭 구성 변경

- 변경 이유: `12주차_주간보고서_02_DATA_TADA.pdf`의 3번 전체 화면 구성을 기존 React 화면 디자인에 반영.
- 비교 화면을 종합해설, 매출, 수요성, 임대료 순으로 구성하고 비교 최초 진입 시 종합해설을 표시. 최대 5개 선택과 화면 크기에 따른 카드 이동을 유지.
- 종합해설에 총매출액, 점포 수, 총 거래 건수의 전년 동분기 비교 막대, 변화율, 점포당 평균 여건과 예시 임대료/면적 범위를 표시. 매출 비교에는 최근 8분기 추이, 수요 비교에는 총 거래 건수와 평균 결제금액을 표시.
- 상세 화면은 매출, 수요성, 입지/주변환경 3개 탭. 매출에 총매출액과 점포당 평균 매출의 과거 추세 및 향후 2분기 예측을 이중 축으로 표시. 거래/유동인구 분포와 매물/주변 카페 조회 흐름을 유지.
- 임대료 비교에서 면적과 층 조건을 선택하고, 월세 합계/면적 합계로 계산한 단가를 설정 면적으로 환산. 매출 대비 비율의 분모는 점포당 분기 평균 매출/3. 보증금/관리비 제외와 가상 매물이라는 한계를 표시.
- API에 비교용 과거 관측값, 거래 건수 YoY, 총매출 예측 필드와 해설의 임대 면적/층 조건을 추가. 기존 예측 fixture는 전년 매출과 총매출 YoY로 동일 총매출을 복원하며, Supabase는 저장된 총매출 예측을 직접 제공. DB 스키마 변경 없음.
- AI 해설의 입력 자료와 프롬프트를 새 탭에 맞춰 갱신. 화면 맥락, 종합 지표, 임대료 계산 결과와 상세 수요의 두 분포를 전달. 프롬프트 버전을 변경해 이전 해설 캐시와 구분.
- 주요 파일: `frontend/src/App.tsx`, `OverviewComparison.tsx`, `Charts.tsx`, `RentComparison.tsx`, `report-metrics.mjs`, `report-layout.css`, `backend/app/analysis.py`, `schemas.py`, `explanations.py`, `supabase_data.py`. README와 API 명세/OpenAPI도 갱신.
- 검증: TypeScript 검사와 Vite production build 통과. 프론트엔드 테스트 4개, 백엔드 테스트 22개 통과. 면적 가중 임대료, 월/분기 단위 환산, 결측과 0, 층 필터, 거래 변화율, 총매출 예측 및 해설 캐시 조건을 확인.
- Chrome 데모 검증: 5개 상권 선택, 최초 종합해설, 카드 이동, 비교/상세 탭, 두 매출 지표 그래프, 면적/층 변경, 주변 카페 메뉴, 유동인구 전환 및 모바일 가로 넘침 검사 통과. 기존 favicon 404와 외부 지도 타일 오류는 앱 JavaScript 오류와 구분.
- 검증 범위: 로컬 데모 자료와 모의 해설 공급자 기준. 실제 Supabase 연결, 유료 LLM 생성 및 운영 배포는 수행하지 않음. `.env`와 원본 보고서는 변경하지 않음. 검증 도구와 화면 캡처는 Git 제외 임시 폴더 `tmp/`에 보관.
