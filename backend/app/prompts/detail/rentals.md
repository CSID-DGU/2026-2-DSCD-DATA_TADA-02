목적:
- 임대매물 탭에서는 한 상권에서 수집된 여러 매물의 월세, 보증금, 면적, 층을 연결해 실제로 조건이 어떻게 다른지 설명한다.

입력 데이터:
- rentals 탭의 rental_count는 상권에서 수집된 임대 광고 수다. monthly_rent_stats와 deposit_stats에는 각 금액을 확보한 매물 수(known_count), 최저액(min_krw), 최고액(max_krw)이 별도로 있다.
- rental_examples는 면적 또는 층과 금액이 함께 확인된 개별 매물 사례다. 각 행의 monthly_rent_krw, deposit_krw, area_m2, floor를 해당 매물의 조건으로 함께 읽는다.

계산 규칙:
- 서버가 집계한 건수와 금액 범위를 그대로 사용한다. 월세와 보증금의 확인 건수는 각각 유지한다. 최솟값과 최댓값이 같으면 한 금액으로 제시한다.

임대매물 탭 해석 규칙:
- summary는 상권명과 수집 매물 수를 한 문장에 담는다. 0건이면 수집된 임대 광고가 없다는 사실을 설명한다.
- '월세와 보증금'은 월세 범위와 보증금 범위를 각 금액의 확인 건수와 함께 제시한다. 두 범위는 서로 별개이며 최저 월세와 최저 보증금을 하나의 매물 조건으로 결합하지 않는다.
- '매물 조건 차이'는 최대 두 매물의 면적과 층, 월세와 보증금을 실제 조합 그대로 연결한다. 서로 다른 조건이 어떻게 함께 나타났는지 설명하고, 면적이나 층을 가격 차이의 원인으로 단정하지 않는다.
- 가격 자료가 비어 있으면 확보된 건수와 조건만 쓴다. 광고에 기록된 금액은 수집된 광고 조건으로 표현한다.

출력 형식:
- summary는 공백 포함 50~120자의 한 문장이다.
- rentals의 blocks는 '월세와 보증금', '매물 조건 차이' 순서이며, 근거가 없으면 둘째 단락을 생략한다.
- 각 block은 1~2문장으로 쓰고, 실제로 사용한 facts 키를 evidence_ids에 넣는다. 본문은 화면에서 필요한 수치, 관측된 차이, 자료가 확보된 범위만 서술형으로 설명한다.

예시 항목:
- 임대매물 가상 예시: 수집 광고 2건. 1층 40㎡는 월세 220만 원, 보증금 3,000만 원이다. 3층 70㎡는 월세 240만 원, 보증금 2,000만 원이다. 두 매물의 면적, 층, 월세, 보증금을 각각 연결해 설명한다.
- 예시 숫자와 이름은 형식 설명용이다. 실제 답변은 요청의 facts를 사용한다.

[구조화 출력 공통 규칙]
출력은 summary, blocks, caveats로 구성한다. 각 block에는 비어 있지 않은 title, text, evidence_ids가 있다. caveats는 빈 배열 []이다.
page.location_view는 rentals이다. 자료 범위는 수집된 임대 광고와 입력 금액의 확인 건수로 설명한다. caveats는 빈 배열이다.
