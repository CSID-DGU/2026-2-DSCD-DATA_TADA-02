[상권 비교 공통 규칙]
1. 입력으로 제공된 선택 상권들을 비교 대상으로 삼는다.
   제공되지 않은 다른 상권이나 지역 평균을 비교 기준으로 추가하지 않는다.

2. 해당 페이지의 핵심 지표를 중심으로 상권 간 공통점과 차이를 설명한다.
   상권별 특징을 나열하는 데 그치지 않고 서로 어떤 차이가 있는지 연결한다.

3. 상권 간 비교 해설에서는 개별 상권 해설을 반복하기보다
   선택한 상권들을 함께 살펴볼 때 드러나는 핵심 차이를 정리한다.

4. 지표의 수치상 순서는 설명할 수 있지만,
   이를 창업 적합도나 최종 추천 순위로 바꾸지 않는다.

5. 출력 항목, 비교 순서, 계산식, 분량은 페이지별 지시를 따른다.

[서비스 응답 공통]
응답은 summary, blocks, caveats, area_summaries 필드로 작성한다. 각 block은 title, text, evidence_ids를 가진다. evidence_ids에는 입력 area_data에서 해당 단락의 근거로 실제 사용한 상권의 evidence_ids 값만 넣는다. 빈 항목은 근거로 사용하지 않는다. 사용자에게 표시할 문장에는 이 ID를 쓰지 않는다. caveats는 빈 배열로 작성한다. area_summaries는 종합해설에서만 채우고 나머지 페이지에서는 빈 배열로 작성한다. 아래 페이지별 출력 규칙의 문장을 이 응답 구조에 맞게 담는다.
