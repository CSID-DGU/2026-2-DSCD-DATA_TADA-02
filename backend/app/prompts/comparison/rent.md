[목적]
선택한 상권의 수집 매물 기준 평균 월세와 평균 보증금을 비교한다.
월세와 보증금의 차이를 연결하여,
정기적인 월세 지출과 초기에 마련해야 할 보증금 측면에서
어떤 차이가 있는지 쉽게 설명한다.

상권별 해설을 따로 작성하지 않고 전체 비교 해설만 작성한다.

[입력]
사용자 메시지에 제공된 JSON을 분석한다.

area_data의 각 상권에는 다음 정보가 있다.
- area_code, area_name: 상권 코드와 이름
- listing_count: 연결된 수집 매물 수
- checked_at_range: 매물 확인일 범위
- rent_summary.monthly_rent_krw: 월세 집계
- rent_summary.deposit_krw: 보증금 집계

두 집계 항목의 주요 필드는 다음과 같다.
- mean_krw: 해설에 사용할 최종 평균, 원
- method: iqr_filtered_mean 또는 arithmetic_mean
- filter_status: 필터 적용 상태
- available_count: 유효 금액 수
- used_count: 평균 계산에 사용한 매물 수
- missing_count: 금액 누락 수
- invalid_count: 잘못된 값으로 제외한 수
- iqr_excluded_count: IQR 기준으로 제외한 수
- small_sample: 최종 사용 매물이 적은지 여부

aggregation_policy는 집계 방식에 관한 정보다.
_meta는 출처, 조회 정보이며 임대료 비교 지표로 사용하지 않는다.

[집계값 사용]
1. mean_krw를 그대로 사용한다.
   IQR을 다시 계산하거나 매물을 추가로 제외하지 않는다.

2. 월세와 보증금은 별도로 집계되므로
   각각의 used_count와 필터 적용 상태를 확인한다.
   두 평균이 동일한 매물 집합의 조건이라고 가정하지 않는다.

3. mean_krw가 null이면 해당 지표는 비교에서 제외한다.
   연결된 매물이 없다는 이유로 실제 매물이 없다고 설명하지 않는다.

4. IQR 제외를 오류 매물 제거로 표현하지 않는다.
   필터 적용 여부와 제외 건수의 차이가 비교에 영향을 주면
   해당 한계를 짧게 설명한다.

[비교 해석]
1. 먼저 월세와 보증금을 함께 살펴 핵심 차이를 찾는다.

   - 두 평균이 모두 상대적으로 낮음:
     수집 매물 기준으로 월세 지출과 보증금 마련 규모가 모두 작은 편

   - 두 평균이 모두 상대적으로 높음:
     수집 매물 기준으로 월세 지출과 보증금 마련 규모가 모두 큰 편

   - 평균 월세는 낮지만 평균 보증금은 높음:
     월세 지출과 보증금 마련 규모의 방향이 다른 상황

   - 평균 월세는 높지만 평균 보증금은 낮음:
     초기 보증금 규모는 작지만 월세 지출은 큰 상황

   실제로 확인되는 관계만 설명하고,
   월세와 보증금을 합쳐 하나의 우열이나 추천 순위로 만들지 않는다.

2. 모든 상권의 금액을 나열하지 않는다.
   선택 상권을 비교할 때 중요한 차이를 보여주는
   2~3개 상권을 중심으로 설명한다.

3. 금액 차이의 의미를 설명한 뒤 핵심 금액을 근거로 연결한다.
   ‘A는 얼마, B는 얼마’라는 나열만으로 끝내지 않는다.

4. small_sample=true이면 소수 매물에 근거한 결과로 해석한다.
   특히 used_count가 1이면 매물 1건의 조건임을 명시하고,
   이를 상권의 전반적인 임대료 수준이나 확정적인 순위로 확대하지 않는다.

5. 비교 가능한 자료가 부족하면 억지로 차이나 순위를 만들지 않는다.
   확인 가능한 차이와 비교가 제한되는 이유를 설명한다.

[해석 범위]
- 수집 매물의 광고 조건을 비교하며,
  상권 전체의 평균 시세나 실제 계약 금액으로 표현하지 않는다.
- 면적, 층, 입지 조건이 통제된 비교라고 가정하지 않는다.
- 카페 전용으로 선별된 매물이라고 가정하지 않는다.
- 보증금은 초기에 마련해야 하는 금액으로 설명하며,
  소모되는 비용이나 전체 창업비용과 동일하게 취급하지 않는다.
- 월세를 관리비 등까지 포함한 전체 운영비로 표현하지 않는다.
- 임대료만으로 수익성, 창업 적합성을 판단하지 않는다.
- 매물 확인일을 매출 통계의 기준 분기와 동일하게 취급하지 않는다.

[출력]
제목이나 상권별 목록 없이 하나의 문단으로 3문장 작성한다.

1. 첫 문장: 가장 중요한 상권 간 차이와 핵심 금액을 함께 설명한다.
2. 두 번째 문장: 월세와 보증금의 비교 방향이 다른 사례 등
   추가로 중요한 차이를 설명한다.
3. 마지막 문장: 비교에 영향을 주는 자료 한계를 짧게 요약한다.

별도의 전체 요약문을 먼저 쓴 뒤 같은 내용을 다시 설명하지 않는다.
비교 의미와 수치 근거를 같은 문장에 연결한다.
문장 수를 맞추기 위해 여러 내용을 긴 한 문장에 몰아넣지 않는다.

핵심 금액은 전체에서 2~3개만 선택한다.
평균 월세와 보증금을 상권마다 모두 나열하지 않는다.
평균 금액은 ‘만 원’ 단위로 표시하고,
필요하면 소수점 첫째 자리까지 사용한다.

어느 상권의 월세는 높고 보증금은 낮은지 구체적으로 설명한다.
실제 데이터에 그런 차이가 없으면 억지로 만들지 않는다.

집계 건수와 필터 적용 내역은 나열하지 않는다.
다만 매물 1건 기준 등 해석에 중요한 정보는 짧게 명시한다.
자료 없는 상권은 핵심 비교에 필요할 때만 언급한다.

‘평균 매출’ 등 다른 페이지의 지표는 언급하지 않는다.
사용자에게 필요한 최종 비교 해설만 출력한다.

[구조화 출력 매핑]
비교 해설 3문장을 제목 없이 summary 한 문자열에 담는다. blocks는 빈 배열이다. aggregation_policy.selected_floor에 들어 있는 조건의 수집 광고를 사용한다. 광고의 평균 월세와 보증금은 동일 면적 환산값이 아니므로 수집 광고의 집계값이라고 표현한다. 해석 범위가 필요하면 사용 매물 수나 실제 적용된 집계 상태를 근거로 설명한다.
